# AceStudio audit against the November 2026 brief

Date: 2026-11-01. Baseline: 0.9.0 (Phases 1–8). Hardware for AI testing: the connected PC,
RTX 4070 Laptop GPU with **8 GB** VRAM (driver 621.01), 186 GB free on C:. The brief targets
12 GB; by decision of 2026-11-01 everything is tuned and measured on 8 GB, and 12 GB presets
are added but marked untested until run on such a card.

Legend: ✅ exists and is tested · 🔶 partly exists · ⬜ missing.

## 3. Plan (order from the brief, adjusted to the hardware)

1. **UI redesign and identity:** logo, `.ico`, splash, design tokens (charcoal and graphite,
   electric blue), workspace rail with the ten workspaces, Home dashboard, Settings window,
   motion with a reduced-motion switch.
2. **FLUX.2 klein backend** behind the existing worker protocol: install, FP8, offload,
   measured speed and VRAM on the PC. Quality presets (Fast Draft → Maximum) that map to
   steps, resolution and model choice, with measured times shown.
3. **Unified generator:** one AI Studio page for every asset type (type, style, perspective,
   palette, transparency, references, preset, seed, variations); a results grid; refine
   actions (regenerate, region edit, recolour, remove background, upscale, open in editor,
   send to animation, library or export); automatic quality checks.
4. **References and Lock Game Style:** typed references stored per project; style profiles
   (palette, pixel density, outline, shading, light direction, detail); conditioning through
   klein multi-reference plus deterministic palette and pixel-grid constraints; similarity
   scores shown with each result.
5. **Animation:** presets for every action in §5 built from pose templates, with 4/8
   directions; motion for imported sprites through two pipelines: deformation for subtle
   loops (sway, breathe, flicker, wobble, float), which preserves pixels exactly, and AI
   keyframes from klein multi-reference for larger motion; walk cycles per body type; frame
   QA with flags and a preview before export.
6. **Bestiary, asset packs, world builder:** staged and whole-grid generation, both
   benchmarked; cell extraction; batch idle; asset families in a library; a world-builder
   scene with tile layers, props and collision.
7. **Agents:** `acestudio-cli connect claude|codex|cursor|opencode|vscode` writing each
   client's documented configuration and checking that it connects; new MCP tools for the
   features above.
8. **Release:** branded installer, GameMaker and Phaser presets, tests A–G on the PC, licence
   inventory, development log, unresolved issues.

Reference artwork supplied with the brief is used only as local test input on the PC (style
reference test D). It is not committed, shipped or reproduced; several pieces are signed by
their artists.
