- FLUX.2 [klein] 4B backend:
  - New worker task `image.klein` for text-to-image, up to four references and region edits
    (inpaint). FP8 storage for the transformer and Qwen3 text encoder under 14 GB, model
    offload under 20 GB.
  - The pixel-art LoRA is merged into the weights before FP8 storage.
  - Catalogue entries for klein and its pixel-art LoRA (Apache-2.0), pinned through
    `pin-model.yml`.
- Generation can cut out the background at full size before pixel reduction; the reduction
  now keeps hard alpha.
- Unified generator (AI Studio workspace):
  - Covers 20 asset types, 6 styles, 5 perspectives, sizes, palette, transparency,
    references, model choice and four quality presets.
  - Every result is checked for size, cut-off parts, opaque background, stray pixels, soft
    alpha, splits, colour count and palette drift.
  - Results can be opened, added as a layer, animated, used as a reference or turned into
    more like this.
- Style engine (P4):
  - Reference images have a role (character, style, palette, environment, creature, equipment,
    animation, composition). Each role adds an instruction that limits what the model takes
    from that image. Palette references are not sent to the model; their colours constrain
    the pixel reduction.
  - Style profiles (`core/StyleProfile`) are measured from references without AI: palette,
    pixel scale, outline, shading depth, light direction, saturation, value and detail.
  - Lock Game Style applies a profile to every generation at three strengths: words only;
    words plus reference images; or both plus the exact palette.
  - Each result is scored against the locked style and flagged below the variation threshold
    (80 / 70 / 55 %).
- Animation (P5):
  - `core/SpriteMotion` animates any still sprite without AI in 22 actions plus custom.
  - The silhouette is split into body, feet and ground shadow, and each frame moves the parts
    with rigid transforms sampled nearest-neighbour, so frames use only the sprite's colours.
  - Walks adapt to the subject: two feet alternate, four trot in diagonal pairs, a blob hops,
    an object rocks.
  - Clip checks report size drift, frame jumps and loop seams.
  - Available as Animation › Animate Sprite… (live preview, a tag per action, or strips),
    `acestudio-cli animate`, and from AI Studio.
  - Tried on a 29×57 armoured knight whose legs are drawn together. It is classified as an
    object and rocks rather than walks. Its ground shadow stays on the ground through a
    jump. Setting the body to Two legs swings the lower half as legs.
  - Character Pack (AI Studio): the missing directions (front, back, diagonals) are generated
    with the result as a character reference (klein, same seed), the left-facing ones are
    mirrored, and all of them are animated. Not yet run on the GPU: klein is not installed
    on the test PC.
- Bestiary, packs, pet (P6):
  - `gen::extractGrid` places its cuts in the emptiest gaps near the expected lines and
    removes the background per cell. It is unit-tested on an uneven synthetic sheet. Not yet
    run on a real generated sheet.
  - World Builder map canvas plus `.acemap` files and Tiled `.tmx` export. The `.tmx` was
    parsed with Python's XML parser (layers 30×12 = 360 cells, tilesets, image layer and
    object groups as written). It has not been opened in Tiled.
